使い方と注意事項
基本操作
  • 動画を選ぶと音声トラックを確認します。
  • 音声が複数ある場合は、取り出す音声を選びます。
  • 保存方法を「元の音質のまま / M4A / MP3 / WAV」から選び、結果から音声ファイルを保存します。
  • 出力ファイル名は抽出前に編集できます。「動画名を使う」で動画名に-audioを付けた名前へ戻せます。拡張子は自動で付き、名前の途中のドットは保持します。変更は次の抽出に適用され、作成済みの音声の名前は変わりません。
  • ヘッダーのEN / JAで言語を切り替えられます。ヘルプと確認画面は本文をスクロールしても閉じるボタンを表示します。閉じるボタン、Escキー、背景クリックで閉じられ、確認を閉じても作成済み音声は残ります。
プライバシー
選んだ動画と作成した音声はブラウザー内だけで処理され、このアプリから外部へ送信されません。
端末に保存する設定
言語、最後に選んだ保存形式、M4A / MP3のビットレート、MP3のモノラル / ステレオ設定だけをブラウザーに保存します。動画名、ファイル内容、処理履歴、生成音声は保存しません。
オフライン利用
処理エンジンをHTML内に含み、実行中の外部通信はありません。保存したHTMLは対応ブラウザーで file:// から直接開いて使えます。
対応範囲
無劣化抽出は AAC→M4A、ALAC→M4A、MP3→MP3、Opus→OPUS、Vorbis→OGG、FLAC→FLAC を検証済みです。変換は M4A（AAC 128 / 192 / 256 kbps）、MP3（128 / 192 / 256 / 320 kbps、モノラル / ステレオ）、WAV（PCM 16bit）に対応します。AC-3 / E-AC-3 はこのバージョンでは未対応です。
