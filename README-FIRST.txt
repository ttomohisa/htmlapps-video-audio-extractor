Video Audio Extractor / 動画から音声抽出

Start here:
1. Read AGENTS.md.
2. Read APP_SPEC.md.
3. Edit src/index.template.html, never generated dist HTML directly.
4. Use the dedicated video-audio-extractor profile from htmlapps-ffmpeg-wasm-builder.
5. Run build-standalone.bat on Windows for the canonical build.

The production build pins FFmpeg WASM Builder v1.10.0 and its exact tagged Release asset provenance.
